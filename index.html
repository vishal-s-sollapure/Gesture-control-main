Touchless Desktop Control using AI Hand Tracking

Control your laptop or desktop computer seamlessly using real-time webcam hand gestures. Built with Python, OpenCV, MediaPipe, PyAutoGUI, and NumPy.

View on GitHub 🚀 Local Installation Guide
🎯

Real-Time 3D Landmark Tracking

Uses MediaPipe 21 3D hand landmarks with scale-invariant distance metrics for accurate gesture recognition at any distance.

🌊

Exponential Motion Smoothing

Applies EMA smoothing and dead-zone filtering to eliminate cursor shaking and ensure fluid mouse positioning.

🛡️

Safety First Architecture

Launches in PAUSED state by default. Includes ESC hotkey emergency stop, closed fist pause gesture, and automatic drag release.

⏱️

Decoupled Double Click Timing

Reliable double-click detection without conflict with general action cooldowns or single click spam.

Mapped Hand Gestures

Gesture Icon Gesture Name Hand Pose Description System Action
☝️ Cursor Movement Index finger extended, other fingers folded Moves mouse cursor smoothly
🤏 Left Click Thumb tip & Index tip pinch together Single left mouse click
✌️ Right Click Index & Middle fingers extended (V sign) Single right mouse click
✋ Scroll Open palm moved vertically up/down Scrolls page up / down
✊🤏 Drag & Drop Sustained Thumb & Index pinch Holds left click, releases on open pinch
🤏🤏 Double Click Two quick pinches within 0.4 seconds Double left mouse click
👍 Media Play/Pause Thumbs Up (Thumb up, others folded) Play / Pause media playback
👉 Next Track Horizontal open-palm swipe to right Skips to Next Track
👈 Previous Track Horizontal open-palm swipe to left Skips to Previous Track
✊ Emergency Pause Closed fist (all fingers folded) Instantly pauses gesture control

How to Run Locally

Clone the repository and run locally on your laptop with webcam access:

# 1. Clone repository
git clone https://github.com/vishal-s-sollapure/Gesture-control-main.git
cd Gesture-control-main

# 2. Setup virtual environment & dependencies
python -m venv venv
venv\Scripts\activate # On Windows
pip install --no-build-isolation -r requirements.txt

# 3. Launch GestureControl AI
python main.py
